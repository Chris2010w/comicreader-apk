# Comic Reader (Android)

Εφαρμογή ανάγνωσης comics (CBZ + PDF) για Android: αναστροφή σελίδας (book style), βιομετρικό κλείδωμα, welcome animation.

## Πώς βγαίνει το APK (χωρίς Android Studio)

1. Φτιάξε νέο repository στο GitHub: https://github.com/new
2. Ανέβασε ΟΛΑ τα αρχεία (μαζί με τον κρυφό φάκελο `.github`) στο repository.
3. Πήγαινε στο tab **Actions** → **Build APK** → **Run workflow** (ή απλά κάνε push).
4. Όταν τελειώσει (~5-10 λεπτά), άνοιξε το run και κατέβασε το artifact **ComicReader-APK** (zip με το `app-debug.apk`).
5. Στείλε το APK στο κινητό, άνοιξέ το και επίτρεψε «Εγκατάσταση από άγνωστες πηγές» όταν σε ρωτήσει.

## Χρήση

- Πρώτη φορά: γράφεις το όνομά σου και διαλέγεις τον φάκελο με τα comics (υποφάκελοι μέχρι 3 επίπεδα).
- Αγγίζεις δεξιά = επόμενη σελίδα, αριστερά = προηγούμενη, στο κέντρο = εμφάνιση/απόκρυψη χειριστηρίων. Και swipe δουλεύει.
- Μενού ⋮ (στη βιβλιοθήκη ή μέσα στο comic): αναστροφή με animation ή χωρίς, κλείδωμα ON/OFF, αλλαγή ονόματος/φακέλου.
- Θυμάται τη σελίδα που έμεινες σε κάθε comic.
